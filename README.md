# Simulação de engenharia social

Apresentação interativa que fiz para uma aula de Segurança da Informação.

A turma recebia um QR Code para "avaliar a apresentação do colega". O formulário parecia oficial e pedia nome, idade, curso, e-mail e telefone. Ao enviar, a tela virava e mostrava tudo o que um atacante teria em mãos com aqueles dados, e o que ele faria com eles: golpe pelo WhatsApp, Pix falso, venda de contatos.

A ideia era mostrar como é fácil entregar informação pessoal quando o pedido parece legítimo.

## É seguro?

Sim. Nada sai do navegador de quem preenche. Não existe back-end, banco de dados ou envio de informação para lugar nenhum. Os dados aparecem só na própria tela, para a demonstração.
